# Dom Barão Delivery

Prévia de site responsivo em preto e dourado para a Dom Barão Delivery.

## Executar

Abra `index.html` no navegador ou sirva esta pasta com um servidor HTTP estático. Não há dependências nem etapa de build.

## Recursos

- Identidade visual com o logo fornecido e imagem ilustrativa de capa.
- Categorias de bebidas com filtros.
- Apresentação da marca e etapas do pedido.
- Layout adaptável para celular e computador.

O catálogo é demonstrativo. Os botões de pedido abrem um aviso de prévia; o WhatsApp oficial, os produtos e os preços ainda precisam ser configurados.

## Arquivos

- `index.html`: conteúdo da página.
- `style.css`: estilos e layout responsivo.
- `app.js`: filtros e janela de demonstração de pedido.
- `assets/`: logo e imagem de capa.

As fontes são carregadas pelo Google Fonts, com alternativas locais de fallback. A capa foi criada com a ferramenta integrada de geração de imagens a partir do conceito: bebidas geladas sobre mármore preto, iluminação dourada e fundo de bar escuro, sem marcas ou texto.

## Hospedagem

Publique esta pasta como site estático, usando a raiz como diretório de publicação. Para GitHub Pages, selecione a branch `main` e a pasta `/ (root)` nas configurações do repositório.
